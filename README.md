## Description
A smart wardrobe system designed to simplify daily styling by tracking clothing inventory and generating personalized outfit recommendations based on available items and individual taste.

## Deployment
### Prerequisites
* (Recommended) virtual environment manager (`venv` or `conda`)
### Set Up
1. **Clone the repository**:
```bash
   git clone [https://github.com/tu-usuario/wardrobe-iot.git](https://github.com/tu-usuario/wardrobe-iot.git)
cd wardrobe-iot
```
2. Create a virtual environment (venv):
```bash
  python3 -m venv venv
source venv/bin/activate
```
3. Install dependecies: 
```bash
   pip install -r requirements.txt 
```
